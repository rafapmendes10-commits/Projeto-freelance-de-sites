Automação gratuita

Sua base de leads atualizada sozinha, toda semana

O projeto inclui um robô que roda no GitHub Actions, gratuito para repositórios públicos e com cota mensal generosa para privados. Ele executa as buscas que você definir, enriquece os dados visitando o site de cada empresa e entrega as planilhas prontas.

  • Agendamento semanal ou execução manual com um clique
  • Enriquecimento automático de e-mail e Instagram a partir dos sites
  • CSV e JSON salvos no repositório e prontos para importar no CRM
  • Integração opcional com o Google Places usando um segredo do repositório

Dúvidas frequentes

Perguntas que todo mundo faz

É gratuito de verdade?

Sim. A fonte padrão é o OpenStreetMap, uma base de mapas aberta e colaborativa, consultada sem chave e sem custo. O site é estático e pode ser hospedado de graça no GitHub Pages.

De onde vêm os dados?

Do OpenStreetMap, por meio das APIs públicas Nominatim e Overpass, sob a licença ODbL. Opcionalmente, do Google Places com a sua chave. Em ambos os casos são dados públicos de estabelecimentos comerciais.

Por que alguns leads vêm sem telefone?

Porque a informação não foi cadastrada no mapa. Use os filtros "Com telefone" e "Com WhatsApp" para trabalhar apenas os completos, ou ative o Google Places e o enriquecimento automático para ampliar a cobertura.

Usar esses contatos está de acordo com a LGPD?

Os dados são de empresas e foram publicados para contato comercial. Ainda assim, aborde com finalidade legítima, identifique-se, ofereça algo relevante e respeite quem pedir para não receber mensagens. Evite listas de pessoas físicas.

O disparo no WhatsApp é automático?

É assistido: o painel prepara cada mensagem personalizada e abre a conversa no seu WhatsApp, você só confirma o envio. Esse formato é gratuito e muito mais seguro contra bloqueios do que robôs de envio em massa.

Onde ficam salvos meus leads?

No armazenamento local do seu navegador. Nada é enviado para servidores do Radar Leads. Use o backup em Configurações para levar seus dados para outro computador.

Consigo rodar as buscas automaticamente?

Sim. Edite o arquivo de buscas do repositório e o GitHub Actions executa tudo semanalmente, salvando as planilhas. Também é possível disparar manualmente informando nicho e cidade.
